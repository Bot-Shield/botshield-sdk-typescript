# Gate

The gate as the person meets it on the arrival card — display facts about the GATE, never about anyone. Null when the request has no gate.

## Example Usage

```typescript
import { Gate } from "botshield-sdk/models/operations";

let value: Gate = {
  destinationHost: "example.com",
  perPerson: {
    limit: 2,
    window: "ever",
  },
  policyLine: "2 per person · ever",
};
```
