# RequestPasskeyCompleteDataData

The outcome only — no session, no BotShield ID, no token. On `verified` the completion has already run exactly as in the app (token minted, webhook sent — including `act` on an action request); collect the result as you already do.

## Example Usage

```typescript
import { RequestPasskeyCompleteDataData } from "botshield-sdk/models/operations";

let value: RequestPasskeyCompleteDataData = {
  outcome: "verified",
};
```
