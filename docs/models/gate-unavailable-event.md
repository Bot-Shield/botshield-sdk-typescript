# GateUnavailableEvent

Webhook `gate.unavailable` (delivered by Svix to your endpoint). Identity-free. Sent once per request when it ends without a pass: the person declined, the check failed or was refused, or a newer check replaced it. Not modeled as an OpenAPI `webhooks` entry, like `GateHumanVerifiedEvent`.

## Example Usage

```typescript
import { GateUnavailableEvent } from "botshield-sdk/models";

let value: GateUnavailableEvent = {
  type: "gate.unavailable",
  eventId: "<id>",
  requestId: "<id>",
  failedAt: new Date("2024-04-30T10:58:07.724Z"),
  verdict: "unavailable",
  reason: "platform_declined",
  failureCode: "superseded",
  environment: "production",
};
```
