# GatePolicyDoc

A gate's policy document (versioned; validated whole). Unknown fields are refused. When `preset` is also sent on the create call, the preset pre-fills these fields and any field here overrides it.

## Example Usage

```typescript
import { GatePolicyDoc } from "botshield-sdk/models";

let value: GatePolicyDoc = {
  version: 3,
  preset: "presale",
  link: "required",
  schedule: {
    opensAt: new Date("2026-11-20T17:00:00Z"),
    closesAt: null,
  },
  passesPerPerson: {
    limit: 2,
    window: "ever",
  },
  realDaysAtLeast: 0,
};
```
