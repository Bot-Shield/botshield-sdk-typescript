# GateHumanVerifiedEvent

Webhook `gate.human_verified` (delivered by Svix to your endpoint). Identity-free. Sent once per request when a live human is proven — from the BotShield app or the inline passkey lane alike. Not modeled as an OpenAPI `webhooks` entry: the Speakeasy plan in use skips webhooks (business tier).

## Example Usage

```typescript
import { GateHumanVerifiedEvent } from "botshield-sdk/models";

let value: GateHumanVerifiedEvent = {
  type: "gate.human_verified",
  eventId: "<id>",
  requestId: "<id>",
  verifiedAt: new Date("2024-10-11T06:49:18.966Z"),
  verdict: "pass",
  trusted: false,
  firstTime: false,
  environment: "development",
  act: "unlink:acct_4417",
};
```
